# Auto Farm (Fabric, Minecraft 1.21.11)

Client-side mod. Tombol: **G** = buka GUI, **H** = ON/OFF farming.

- Mode **Hancurkan**: blok dihancurkan lalu ditanam ulang otomatis (bibit di hotbar).
- Mode **Klik Kanan**: cukup di-klik kanan (sweet berry, glow berries, crop mod lain).
- Tetap jalan saat ESC / inventory / alt-tab (opsi "Jalan di background").

## Build
```
./gradlew build
```
Hasil: `build/libs/autofarm-1.0.0.jar`
